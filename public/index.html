About This Demo

This demonstration showcases how OpenFGA (Fine-Grained Authorization) secures a RAG (Retrieval-Augmented Generation) pipeline in a realistic enterprise environment. The same question produces different responses based on the user's authorization level.

Fine-Grained Authorization

OpenFGA enforces access control at the document level, ensuring users only see information they're authorized to access.

Intelligent Retrieval

The system uses vector similarity search to find relevant documents, then filters results based on user permissions.

Context-Aware Responses

LLM responses are generated based only on the authorized documents, demonstrating real-time permission enforcement.

Multi-Persona Testing

Test the same question with different user personas to see how authorization affects the response scope and content.
